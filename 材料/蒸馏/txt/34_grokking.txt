 1. 研究背景与动机
 
 1.1 研究背景
 
 近年来，强化学习（RL）技术被广泛应用于提升大型语言模型（LLMs）的推理能力，然而，RL 在这一过程中扮演的角色——究竟是仅仅强化（Sharpening）模型已有的潜在能力，还是能够发现（Discovery）并注入全新的推理策略，一直存在根本性的学术争议 。

 争议核心：Sharpening vs. Discovery 
 一部分研究人员持怀疑论观点，认为 RL只能激发模型在预训练参数中已潜藏的知识或能力。他们认为，即使 RL 训练后的模型在pass@K（大采样次数下的通过率）性能上有所提高，这可能仅仅是提高了现有解决方案的采样效率，模型的表征能力和最终推理边界仍受限于其基座模型。从算法机理上看，主流RL方法依赖于比较同一prompt下多个样本的奖励信号，如果基础模型对某类任务的通过率始终为零，意味着所有采样都无法提供有效的奖励差异，梯度更新将失去方向，模型难以突破这一能力瓶颈。与之相对，乐观论观点则认为RL 是一种有效的手段，能够解锁基座模型中原本无法触及的、涌现式的问题解决能力。

 传统评估的局限性与数据污染风险 
 为解决这一争议，现有评估方法的局限性必须被克服。传统的开放性基准，例如数学或编程数据集（如Numina-Math、OpenCodeReasoning），往往混合了多种主题和难度，使得研究人员难以精确区分模型能力的提高是源于简单的“能力强化”还是“真正习得”了新策略。更重要的是，评估结果的可靠性面临数据污染的严重威胁。有研究指出，某些 LLM 系列在流行数学基准上表现出的“反常有效性”（例如，随机奖励也能提升性能），实质上是模型在预训练阶段记忆了基准数据，导致其评估结果依赖记忆而非真正的推理。因此，要准确衡量 RL 的真实效果，研究迫切需要一个具有受控分布和可验证OOD（Out-of-Distribution，分布外）特性的清洁基准，以排除数据混淆，并能精确归因 RL 带来的能力增益。

 1.2 研究动机
 
 本研究的核心动机是，通过构建一个结构化、可隔离技能的测试平台——DELTA 基准，系统性地回答上述争议，并探索 RL 驱动的 LLM 推理能力的边界。研究引入了两个明确的可测试标准：
 
 可学习性（Learnability），即 RL 能否在基座模型即使在大采样次数（如pass@128）下仍完全失败的任务（pass@K=0）上注入新推理策略；
 泛化性（Generalization），即如果新策略被习得，它们是否能系统地、可靠地转移到不同的 OOD 测试场景。
 
 对于pass@K=0这类任务，基座模型完全无法给出任何正确输出，标准 RL 无法启动学习。因此，探究何种训练配方，尤其是奖励机制和数据组织，是克服奖励稀疏性、触发策略发现并引发 Grokking 这一突变相变的关键机制，成为研究的首要任务。最后，研究旨在通过系统评估新策略的转移性，界定 RL 驱动推理的上限与极限。通过 Boden 创造力模型的三轴（探索性、组合性、变革性）对泛化进行分类评估，从而系统地绘制出 LLM 习得新算法技能后的能力边界。
 
 2. 核心方法解析
 
 2.1 DELTA
 
 为解决传统评测方法的不足，本研究提出了 DELTA（Distributional Evaluation of Learnability and Transferrability in Algorithmic Coding），这是一个涵盖多种编程场景、问题完全由合成生成的受控评测基准。
 
 DELTA 中的每一个问题均通过模板化生成器动态创建，使研究者能够精准控制题目难度与数据分布。这种机制从根源上杜绝了预训练数据泄漏的可能，也为准确追溯模型能力提升的来源提供了清晰依据。
 
 相比数学推导或形式逻辑类任务，编程评测还具备一项天然优势：执行结果可通过测试用例提供细粒度反馈。这种基于通过率的连续奖励信号，有效缓解了强化学习过程中奖励稀疏的难题，为训练过程提供了稳定、可迭代的学习信号。
 
 DELTA 包含了五大主要问题域，涵盖了从自定义语法到物理模拟再到形式逻辑的多种编程挑战，确保了测试的全面性：
 
 Manufactoria： 用于测试可学习性的 OOD 编程谜题。
 BouncingSim： 2D 物理模拟编程任务，用于轴向泛化性研究。
 竞争性编程： 涵盖 Mo’s 算法、分段树分治等复杂算法。
 SQL： 文本到 SQL 查询逻辑。
 LEAN： 形式化数学证明（代数、数论、几何等）。
 
 2.2 阶段性奖励机制（The Grokking Recipe）
 
 标准的 RL 训练（如 GRPO/PPO）在代码生成任务上通常依赖稀疏的二元奖励（完美解决方案得 +1，其余为 0）。这种机制在pass@K=0的任务上会彻底失败，因为模型永远无法获得正梯度信号，训练曲线停滞不前。
 
 本研究的核心突破在于引入了稠密到二元（Dense-to-Binary）的阶段性奖励方案，这是诱发 Grokking 现象的关键。该奖励方案如下：
 
 Warm-up：稠密奖励
 
 在训练初期，模型采用Per-test Pass Rate作为奖励信号。这是一个连续值，范围在01之间，即使程序只通过了部分测试案例，模型也能获得正反馈。
 这个阶段的目标是引导模型的策略探索脱离全零区域，鼓励模型产生部分正确的进展，将探索引向全解可及的区域。如下图所示，Per-test Pass Rate在训练过程中会有很小的一个增长（至少不是0）。

 2. Exploration and grokking：严格二元奖励
 
 一旦模型通过warm up阶段获得了初步的策略牵引力，奖励信号随即切换为严格的二元全通过奖励。
 这个阶段的目标是确保解决方案的精确性和一致性，将探索阶段发现的潜在策略“锁定”并强化为经过验证的、可执行的完整程序。
 
 如上图所示，在约450步内，模型仍处于探索阶段，Full Pass Rate持续低于1%。经过一个顿悟时刻后，模型发现了破解该问题的关键策略。随后训练进入收敛阶段，强化学习逐渐聚焦并持续强化这条成功的推理路径。当模型收敛时，强化学习训练的模型在pass@k指标上相比基准模型实现了近100%的绝对提升。
 
 2.3 Grokking 的加速策略探索与局限性
 
 为了缩短 Grokking 出现前的漫长的探索期（例如在 Manufactoria-HAS 任务上，该探索期持续约 450 步），研究人员探索了几种加速技术。

 Experience Replay： 记录并重用成功的推理轨迹，可以有效缓解正奖励信号的稀疏性。实验显示，这种策略确实能使 Grokking 提前出现，提高探索效率 。
 Feedback-in-the-Loop： 将验证器的失败测试案例反馈直接注入到生成过程中，鼓励模型进行自我修正。这种方法进一步加快了 Grokking 的时刻，但由于反馈是 Off-Policy 的，其引入也可能牺牲训练的稳定性 。
 
 研究还对比了通过问题家族的课程学习是否能作为上述两阶段策略的替代方案 。实验显示，课程学习的成功高度依赖于任务之间的结构兼容性。例如，只有当课程家族（如 REGEX）与目标家族（HAS）都围绕子模式匹配展开时，转移才能成功；而如果中间家族（如 COMPR）涉及完全不同的数值计算逻辑，则转移失败 。
 
 这一发现表明，虽然课程学习在特定情况下有效，但稠密奖励热身具有更强的普适性，因为它不要求设计结构高度对齐的中间任务。
 
 3. 实验
 
 3.1 实验设置
 
 本研究主要使用 Qwen3-4B-Instruct 作为参考指令调整模型 。
 
 在可学习性研究中，核心任务选择了 Manufactoria-HAS 家族（属于 Manufactoria 的 Easy 难度层级）。该任务的特殊性在于，基座模型在其上的性能极差，即使在大采样尝试次数下（pass@128）通过率也接近0 。
 
 在泛化性研究中，主要使用 BouncingSim（2D 物理模拟编码任务）。训练集是 Basic 难度的六个单技能家族（如旋转物体、移动箱体、重力等）的混合 。
 
 3.2 RL Grokking 现象验证
 
 通过实施稠密到二元的阶段性奖励机制，研究人员在 Manufactoria-HAS 任务上观察到了标志性的 Grokking 现象 ：
 
 长探索期： 模型在训练初期（约 450 步）长时间停留在探索阶段，Full Pass Rate持续低于1%。
 Grokking： 在某一刻，模型的性能突然从近乎零跃升至近乎100%的准确率，表明模型成功发现了解决该问题家族的关键策略 。
 结果： 最终，RL 训练后的模型在pass@K上实现了相对于基座模型近100%的绝对提升 。
 
 这一现象被证实具有跨任务和跨模型的普适性。相同的的收敛模式不仅出现在 Manufactoria-REGEX（符号编程）上，也出现在 BouncingSim-All（物理模拟编码）等不同领域，甚至在更大规模的模型（如 Nemotron-14B）上也得到了复现。
 
 Grokkting 的稳定性与边界 
 
 虽然 Grokking 带来了显著的能力提升，但研究也揭示了训练中的稳定性挑战。图 10(a) 的曲线显示，一旦 Grokking 达到收敛，如果继续盲目延长训练步数，可能会触发RL Collapse，导致性能重新下降 。这表明 Grokking 标志着模型找到了一个高奖励区域的稳定策略，但持续过度优化策略分布可能使模型对探索或微小分布变化变得脆弱。因此，在 RL Grokking 阶段的训练中，需要采取精细的监控和稳定性机制（例如及时停止），而不是单纯依赖更长的训练时间。
 
 此外，稠密奖励warm up的有效性也存在边界。对于某些结构性难度极高的 Manufactoria 家族（例如 Manufactoria-PREPEND），即使使用稠密奖励，模型也无法逃脱全零状态 。这表明稠密奖励的有效性依赖于基座模型是否具备足够的底层组件能力，使得部分正确的解决方案在探索空间中是可被构建的。对于结构性难度过高的任务，梯度信号可能过于微弱，warm up机制将失效，无法引导模型找到突破口 。
 
 3.3 泛化性评估
 
 研究人员通过 BouncingSim 任务，系统地评估了通过 RL 习得的编程技能在三个轴向上的转移边界 。
 
 Explorative generalization 
 模型对参数化难度变化的泛化能力表现得稳健，但存在连续的衰减。例如，从训练时的标准容器尺寸推广到测试时碰撞更密集、几何结构更复杂的 Easy/Medium 变体时，性能仍能保持在 50% 到 75% 之间。然而，当难度进一步增加至 Hard 变体时，准确率会急剧下降到个位数 。这表明 RL 能够很好地推广到已学技能的参数空间扩展，但这种推广能力是有限的。
 
 Compositional Generalization 
 模型在分别训练处理旋转箱体（ROTAT_BOX）和旋转物体（ROTAT_OBJ）后，能够成功整合技能，解决同时旋转的复杂场景（ROTAT_BOX_OBJ），准确率达到 60% 到 70% 。这种成功归因于编程任务的结构化组合性。模型习得的是处理独立物理模块的代码，组合任务本质上是合并这些模块，而非要求模型发明全新的推理步骤或策略 。
 
 Transformative Generalization 
 面对需要发现全新定性结构（例如，特殊初始条件下能产生完美周期性轨迹）的任务，模型表现持续接近于零 。这与 LLM 在符号数学等领域遇到的变革性泛化挑战是一致的。这揭示了当前 RL 驱动的 LLM 在进行深层次的定性创新方面存在显著局限 。
 
 4. 总结
 
 本研究通过 DELTA 这一清洁、受控的 OOD 基准，明确了 RL 在大型语言模型推理能力提升中的作用边界。研究证实，RL 的能力并非仅限于强化。在正确的训练策略下，RL 确实能实现发现全新的、基模无法执行的程序策略。这种能力突破表现为典型的“grokking”模式——长期的探索后突然出现的性能跃迁。
 
 其中，Dense-to-Binary阶段性奖励机制是实现 Grokking 和策略发现的决定性因素 。这一机制通过在初期提供细粒度的、可用的梯度信号，帮助模型跨越奖励稀疏性的鸿沟，最终将探索中发现的潜在策略锁定为精确、可执行的算法。
 
 在泛化性方面，RL 习得的策略在探索性泛化上表现稳健，在组合性泛化上表现出色，这归因于 LLM 具备强大的程序模块结构化整合能力 。然而，变革性泛化上的持续失败，揭示了当前 RL 驱动的 LLM 难以进行深层次的定性创新，即发明与训练数据范式完全不同的新算法或发现新的数学结构。
 
 5. 一点看法
 
 本文思想要迁移到某个具体的困难任务上，重点应该是如何构造warm up阶段的奖励机制。例如，对于一些困难数学题来讲，Base模型在大采样条件下可能一个都无法做对，那么在前期可以设置一些连续的奖励信号：思维链推导中有一些步骤是对的，那么可以适当加分。待连续奖励提升到一定值时，再切换为严格的二元奖励。
